# Question 1 #
## What are the components of an HTTP request? ##
A request has an endpoint, headers, a request type, and optionally a body/payload.

# Question 2 #
## What are the components of an HTTP response? ##
A response has a header, status code, and a body/payload.

# Question 3 #
## What are the 2 most popular payload formats? ##
JSON and XML

# Question 4 #
## Explain JSON format in your own words. Give an example. ##
JSON is a key value pair data structure like a map or dictionary. Each key has a type of string and the value can be of any type including non-primitive types such as arrays or another object.
